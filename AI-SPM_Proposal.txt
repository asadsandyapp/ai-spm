Section 01–02

1. Executive Summary
Our proposed enterprise response to the AI-SPM MVP requirements.

Employees use AI tools such as ChatGPT and Claude directly in their browsers — creating uncontrolled pathways for data
leakage and policy violations. We propose a dual-component platform: a lightweight endpoint agent installed on each
workstation that intercepts AI traffic, and a central AI security gateway on the company server that inspects every prompt and
response before it reaches any external LLM provider.
Our Approach: Users continue using ChatGPT, Claude, and Gemini as they do today. The endpoint agent runs silently in the
background, routing all AI traffic through our security gateway. The gateway applies PII masking, policy enforcement, and threat
detection — then forwards only safe, sanitized prompts to the AI provider. Security administrators manage the platform via a Reactbased admin dashboard.

4. Application Flow
What happens when an employee uses ChatGPT or Claude with the agent installed.
PROMPT LIFECYCLE — AGENT TO GATEWAY TO LLM
1

User Opens AI Tool — Employee opens ChatGPT, Claude, or Gemini in their browser as normal

2

Agent Intercepts — Endpoint agent captures the prompt before it reaches the AI provider directly

3

Agent → Gateway — Prompt sent securely (mTLS) to the AI-SPM gateway on the company server

4

Authentication — Gateway validates agent identity; identifies user, role, and department

5

Policy Check — Is this user allowed to use this model? Is the topic permitted?

6

PII Scan — Presidio detects CNIC, SSN, credit cards, emails; sensitive values masked

7

Threat Scan — Guardrails AI checks for prompt injection and jailbreak attempts

8

Decision — Block (notify user via agent) OR forward sanitized prompt to ChatGPT/Claude

9

LLM Response — AI provider returns answer; gateway scans response for leakage

10

Agent → User — Safe response delivered to browser; user sees answer normally

11

Audit Log — Full event recorded in PostgreSQL; dashboard updated in real time
