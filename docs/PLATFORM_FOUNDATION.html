AI-SPM

Platform Foundation

What we stand up first — foundation pieces and repository layout every later module depends on.

Purpose. Stand up the core platform every later module depends on: a durable store for companies, users, devices, policies, and activity; a secure front door for console and agent traffic; a repeatable local staging environment; health checks for demos; rate limits so one noisy source cannot starve others; and a simple Linux install path so managed PCs can join. Without this foundation, signup, the admin console, and the endpoint agent cannot function.

1. What “foundation” means here

Foundation piece Why it exists
Project structureKnown folders for backend, frontend, agent, deploy, scripts — so work lands in the right place
Local stagingOne Compose stack the team can start for demos and testing
Company data modelOrganizations and related tables every feature hangs off
Customer isolationOne company never sees another company’s data
Health & readinessOperators know the stack is alive before a walkthrough
Secure gatewayFront door + traffic limits for console and agents
Endpoint installSealed Linux package so protection can start on a PC
